API Overview

AUTOPAY Global API enables merchants to accept mobile money payments internationally. Currently supported country: Uganda 🇺🇬.

Payments are processed in UGX using MTN Mobile Money and Airtel Money.

Authentication

All requests require your AUTOPAY Secret API Key.

Authorization: Bearer YOUR_SECRET_KEY
Content-Type: application/json

Base URL

https://autopay.co.ke/api/global

Uganda STK Push

POST /uganda/stk-push

Send a payment request to MTN or Airtel Uganda.

{
 "phone":"256786233749",
 "amount":5000
}

Successful Response

{
 "success":true,
 "message":"Uganda STK Push sent successfully.",
 "data":{
   "reference":"UGX-123456",
   "status":"PENDING",
   "currency":"UGX",
   "amount":5000
 }
}

Check Transaction Status

GET /uganda/status/{reference}

Check the current status of a Uganda payment.

Webhook Notifications

AUTOPAY sends payment confirmation to your configured callback URL.

{
 "reference":"UGX-123456",
 "status":"SUCCESSFUL",
 "amount":5000,
 "phone":"256786233749",
 "currency":"UGX"
}

POST /uganda/swap

Best Practices

  • Never expose your Secret API Key.
  • Always verify webhook payments.
  • Store transaction references.
  • Handle duplicate callbacks safely.
